# Gallery photos

Expected files (JPG, long edge around 1600px):

- `galeria-01.jpg` … `galeria-09.jpg`

The first three are the previews shown in the gallery section; all of them open in the lightbox.

To replace a photo, overwrite the file keeping the same name.
To add more, drop the new file here and add an entry to `gallery.images` in `scripts/invitation-data.js`
(remove an entry to show fewer photos).
